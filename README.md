# Website giới thiệu Đức Văn Karaoke

## Cách mở website bằng Visual Studio Code
1. Giải nén file ZIP.
2. Mở Visual Studio Code.
3. Chọn **File > Open Folder...** và chọn thư mục `duc-van-karaoke-website`.
4. Mở file `index.html`.
5. Nhấn chuột phải và chọn **Open with Live Server** (nếu đã cài tiện ích Live Server).
   - Nếu chưa cài Live Server, bạn có thể mở trực tiếp file `index.html` bằng trình duyệt.

## Các file chính
- `index.html`: nội dung và cấu trúc trang web (HTML).
- `style.css`: màu sắc, bố cục và giao diện (CSS).
- `script.js`: JavaScript đơn giản hiển thị năm hiện tại.
- `images/`: bốn ảnh quán do bạn gửi.

## Chỗ có thể tự chỉnh sửa
- Đổi nội dung giới thiệu trong `index.html`.
- Đổi màu cam/đen trong `style.css`.
- Thay ảnh bằng cách chép ảnh mới vào thư mục `images` và sửa tên file trong `index.html`.

Lưu ý: Địa chỉ và số điện thoại được đọc từ biển hiệu trong ảnh; hãy kiểm tra lại trước khi công khai website.
